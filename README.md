# 相位支切室

光学干涉包裹相位的支切（branch-cut）操作室：查看包裹相位、振幅质量与
残差电荷，自动/手动配对残差并编辑不可跨越的支切，然后运行可追溯的
相位展开。本地服务基于 FastAPI + NumPy，状态持久化在 SQLite。

## 安装与运行

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q && .venv/bin/uvicorn app:app --host 127.0.0.1 --port 5543
```

访问 http://127.0.0.1:5543 即可看到“相位支切室”页面。

## 数据口径

- **包裹相位**：二维网格，差值规约到**半开区间 `(-π, π]`**。恰好等于
  `-π` 的差值映射到 `+π`，恰好等于 `+π` 的保持 `+π`。规约只用
  乘/取整/减（不依赖 `atan2`、`fmod` 等平台相关函数），因此半周期端点
  在不同机器上不会翻转（见 `phasecut/core.py: wrap_phase` 与测试
  `test_wrap_half_open_endpoints_exact`）。
- **残差电荷**：按右→下→左→上的四像素环路对包裹差求和，
  `round(和 / 2π)` 即电荷（±1）。含遮挡像素的环路不参与计算。
- **质量**：`[0, 1]`，遮挡区为 0；残差附近为局部低质量点。
- **遮挡**：遮挡像素不属于任何四边环路，支切路径若穿过遮挡像素会被
  服务器拒绝（HTTP 400）。
- **支切**：连接两个残差（或残差与外边界）的对偶图路径，展开时不可
  跨越。成本为环路网格上的曼哈顿距离。
- **展开**：从固定起始像素洪水展开，每个连通域各自锚定在自身种子的
  包裹值上——**不同连通域只能确定各自的整周期（2π 整数倍）偏置**，
  不做全局最小值假定。未从起始点可达的连通域会在结果中标注。

## 固定 fixture

16×20 网格，第 10 列整体遮挡，把有效区域分成左右两块：

- 左块：残差对 `r0(+1, 环路(4,3))` 与 `r2(-1, 环路(10,5))`；
- 右块：未平衡残差 `r1(+1, 环路(7,15))`，需连到外边界。

fixture 由像素坐标的闭式函数生成（`phasecut/fixture.py`），跨机器、
跨运行逐位一致。

## 页面操作

1. **自动配对**：给出 greedy / optimal / boundary 多个路网候选及总成本。
2. **应用候选为新支切版本**；对当前支切的每条边可**锁定**（后续候选
   强制包含）或**禁止**（后续候选排除）；未平衡残差可一键**连到外边界**。
3. 点击左下图画布设定**起始像素**，**运行展开**：右下图显示展开相位，
   并列出各连通域（未可达连通域高亮，仅确定自身整数偏置）。
4. **运行记录**：每次展开以固定支切版本 + 起始像素入库（SQLite，
   默认 `phasecut.db`，可用环境变量 `PHASECUT_DB` 覆盖），可**重放**
   校验摘要、**导出** JSON、**清空数据库**后**导入**复核。

## 重放与复核

- 重放：`POST /api/runs/{id}/replay` 用运行记录中的支切版本与起始像素
  重新展开，比较 SHA-256 摘要；编辑支切（产生新版本）后重放旧运行仍
  得到原摘要。
- 导出/导入：`GET /api/runs/export` 导出全部支切版本与运行记录；
  `POST /api/admin/clear` 清空；`POST /api/runs/import` 重新导入，
  导入后重放结果一致（测试 `test_export_clear_import_replay`）。

## 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/dataset` | 包裹相位、质量、遮挡、残差列表 |
| POST | `/api/candidates` | 配对候选（可带 `locks` / `forbids`） |
| POST | `/api/cuts` | 保存支切版本（校验不穿遮挡） |
| POST | `/api/unwrap` | 按支切版本 + 起始像素展开并入运行记录 |
| GET | `/api/runs` · POST `/api/runs/{id}/replay` | 运行记录与重放 |
| GET | `/api/runs/export` · POST `/api/runs/import` | 导出 / 导入 |
| POST | `/api/admin/clear` | 清空数据库 |
